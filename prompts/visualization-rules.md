# 可视化数据分析规则

## 目标

所有报告必须包含可视化图表，让老板**扫一眼就抓到重点**，而不是淹没在数字里。

## Webhook 渲染约束

报告通过 webhook 推送到飞书/钉钉/企业微信，图表必须：
- **Markdown 代码块内渲染**：用 ` ``` ` 包裹，确保等宽字体对齐
- **不用 ASCII 框线艺术**：`━━╔══║╚` 在移动端会错位、断裂
- **用半角字符**：`█░─│┌┐└┘├┤┬┴┼` 这些在等宽字体下对齐良好
- **宽度控制在 40 字符以内**：手机竖屏一行最多显示 40 个半角字符
- **emoji 做视觉锚点**：📊📈🔻📍📏 作为图表类型标识
- **每张图表紧跟一句结论**：不让老板自己去"读"图

## 图表数量要求

| 报告类型 | 最少图表数 |
|---------|----------|
| 日报 | 3 张 |
| 周报 | 8 张 |
| 月报 | 10 张 |
| 专题分析 | 4 张 |

## 标准图表库

### 1. 进度条（目标达成）

最高频图表。老板最先看的就是"到哪了"。

```
📏 月度目标进度

GMV目标    ████████████░░░░░░░░  62%  🟡  31.2万/50万
达人目标   ██████████████████░░  89%  🟢  80/90
成本控制   ████████████████░░░░  78%  🟢  3.9万/5万

⏰ 时间进度 67%（第20天/30天）
```

**规则**：
- 进度条总宽 20 字符（█ + ░ = 20）
- `████` 表示已完成，`░░░░` 表示未完成
- 右侧标注百分比 + 状态 emoji + 绝对值
- 🟢 >= 80%，🟡 50%-79%，🔴 < 50%（相对时间进度）

### 2. 条形图（排名对比）

用于 Top N 排名、成本分布等。

```
📊 商务成本 Top5

王五  ██████████████████████████████  2.8万
张三  █████████████░░░░░░░░░░░░░░░░  1.2万
赵六  █████████░░░░░░░░░░░░░░░░░░░░  0.8万
陈七  ██░░░░░░░░░░░░░░░░░░░░░░░░░░░  0.2万
孙八  █░░░░░░░░░░░░░░░░░░░░░░░░░░░░  0.1万

结论：Top3 商务占总成本 65%，集中度偏高
```

**规则**：
- 柱体宽度 30 字符，按最大值等比缩放
- 右侧标注绝对值
- 超阈值的行末尾加 ⚠️
- 最多展示 10 行，否则截断

### 3. 占比分布（等级/类型/用途）

```
📊 达人等级分布

A级  ██████████░░░░░░░░░░░░░░░░░░░░  15%  12人
B级  ████████████████░░░░░░░░░░░░░░  20%  16人
C级  ██████████████████████████░░░░  40%  32人
D级  ████████████████░░░░░░░░░░░░░░  25%  20人

A+B合计：35%（上月 30%，↑ 改善）
```

**规则**：
- 柱体宽 30 字符，按比例填充
- 右侧标注百分比 + 绝对值
- 末尾附合计或对比数据

### 4. 漏斗图（转化分析）

```
🔻 月度转化漏斗

线索  ████████████████████████████████  150  100%
        ↓ 53%
客户  █████████████████████░░░░░░░░░░░   80   53%
        ↓ 44%
商机  ██████████████░░░░░░░░░░░░░░░░░░   35   23%
        ↓ 34%
赢单  █████████░░░░░░░░░░░░░░░░░░░░░░░   12    8%
        ↓ 67%
合同  ██████░░░░░░░░░░░░░░░░░░░░░░░░░░    8    5%

⚠️ 最大断裂：客户→商机，转化率仅 44%
```

**规则**：
- 每层柱体宽 32 字符，按比例缩放
- 层间标注转化率（↓ XX%）
- 最后标注最大断裂点
- 柱体逐层缩短，视觉上形成漏斗感

### 5. 对比表格（核心指标看板）

```
📋 核心指标周看板

| 指标 | 本周 | 上周 | 环比 | 状态 |
|:-----|-----:|-----:|-----:|:----:|
| GMV | **52万** | 48万 | +8.3% | 🟢 |
| 成本 | **3.2万** | 2.8万 | +14.3% | 🟡 |
| ROI | **1:16.2** | 1:17.1 | -5.3% | 🟡 |
| 达人数 | **85** | 82 | +3.7% | 🟢 |

结论：GMV 增长但 ROI 下滑，成本增速超过收入增速
```

**规则**：
- 用 Markdown 表格，不用 ASCII 框线
- 关键数值 **加粗**
- 右对齐数字列（`:-----:` 语法）
- 状态列用 emoji

### 6. 投入产出表（ROI 分析）

```
📊 商务投入产出排名

       投入    GMV产出    ROI
张三   1.2万   15.0万    1:12.5  ✅ 明星
李四   0.3万    5.0万    1:16.7  ✅ 金牛
王五   2.8万    8.0万    1:2.9   ⚠️ 问题
赵六   0.8万    2.0万    1:2.5   ⚠️ 问题
陈七   0.2万    1.5万    1:7.5   👀 观察

结论：王五和赵六投入高但 ROI 低于安全线 1:4
```

**规则**：
- 三列对齐：投入、产出、ROI
- 末尾标注四象限分类（✅ 明星/金牛，⚠️ 问题，👀 观察）
- ROI < 1:4 标注 ⚠️

### 7. 四象限图（战略分析）

```
📍 商务 ROI 矩阵

         高 GMV
           │
    ┌──────┼──────┐
    │ 金牛 │ 明星 │
    │ 李四 │ 张三 │
    ├──────┼──────┤
    │ 观察 │ 问题 │
    │ 陈七 │ 王五 │
    └──────┼──────┘
         低 GMV
   低投入 ←──→ 高投入

明星：张三(投入1.2万,GMV15万,1:12.5)
金牛：李四(投入0.3万,GMV5万,1:16.7)
问题：王五(投入2.8万,GMV8万,1:2.9) ⚠️
观察：陈七(投入0.2万,GMV1.5万,1:7.5)

结论：问题象限有1人，需本周复盘
```

**规则**：
- 四象限用简单框线 `┌┐├┤└┘│─┼`
- 每象限放 1-2 个代表名字
- 下方列出每人具体数据
- 问题象限人员标 ⚠️

### 8. 热力图（交叉矩阵）

```
🔥 平台 × 等级 热力图

          A级    B级    C级    D级
抖音      🔴5人  🟡3人  🟢8人  ⚪2人
快手      🟡2人  🟢4人  🟢6人  ⚪3人
视频号    ⚪0人  🟡2人  🔴7人  ⚪1人
拼多多    ⚪0人  ⚪1人  🟡3人  🔴5人

🔴 高密度  🟡 中密度  🟢 低密度  ⚪ 无

结论：抖音高价值达人密度最高，拼多多以低等级为主
```

**规则**：
- 行=维度1，列=维度2
- 每格用 emoji + 数字
- 底部标注图例
- 🔴 = 该维度最高密度（相对值）

### 9. 风险热力图

```
风险热力图

         履约  成本  结构  目标  增长
严重度    🔴   🟡   🟢   🟡   🟢

```

**规则**：
- 一行严重度（🔴🟡🟢），一行趋势（↑→↓）
- 简洁，不需要框线

## 图表生成规则

### 数据真实性
- 所有图表数据**必须来自 API 返回**，不可编造
- 如果数据不足以生成某张图表，跳过该图表并说明原因
- 不要用占位符数据（XX/XX%），必须填入真实值

### 单位规范
- 金额 > 10000：用"万"（如 3.2万），保留一位小数
- 金额 < 10000：用"元"（如 8500元）
- 百分比：保留一位小数（如 62.5%）
- 人数/单数：用整数

### 对比标注
- 环比增长：`↑ +X%` 或 `+N`
- 环比下降：`↓ -X%` 或 `-N`
- 持平：`→ 0%`
- 超过预警阈值：末尾加 `⚠️`

### 结论规则
- 每张图表**必须**附带一句话结论
- 结论是判断（"集中度偏高需要分散"），不是复述（"Top3占65%"）
- 如果数据健康，结论也可以是正面判断（"结构均衡，继续保持"）
