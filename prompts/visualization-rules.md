# 可视化数据分析规则

## 目标

所有高管报告必须包含足够的可视化图表，让老板一眼看懂经营态势，而不是淹没在数字里。

## 通用原则

### 图表数量
- **日报**：至少 3 张图表
- **周报**：至少 6 张图表
- **月报**：至少 8 张图表
- **专题分析**：至少 4 张图表

### 每张图表必须包含
1. **标题**：简洁描述图表内容
2. **数据**：清晰标注数值和单位
3. **一句话结论**：这张图说明了什么

### 图表设计原则
- 对比优先：能对比的数据不要单独展示
- 趋势优先：能看趋势的不要只看快照
- 排名可视化：Top/Bottom 用条形图，一目了然
- 颜色语义：红色=预警/下降，绿色=健康/增长，黄色=需关注
- 简洁为王：一张图只传达一个核心信息

## 标准图表库

### 1. 趋势类

#### 折线图（适用场景）
- GMV 月度/周度趋势
- 达人增长趋势
- 样品成本变化趋势
- 目标达成进度趋势
- ROI 变化趋势

**输出格式**：
```
📈 [图表标题]

     ▲
  值 │    ╭──╮
     │  ╭╯  ╰──╮
     │╭╯       ╰──
     └──────────────→ 时间
     W1   W2   W3   W4

数据：W1=XX, W2=XX, W3=XX, W4=XX
结论：[一句话]
```

#### 双轴图（适用场景）
- GMV vs 成本对比趋势
- 投入 vs 产出变化
- 数量 vs 金额对比

### 2. 占比类

#### 饼图/环形图（适用场景）
- 成本用途分布
- 达人等级分布
- 平台占比分布
- 账号类型分布

**输出格式**：
```
🔵 [图表标题]

  ┌────────────────────────────┐
  │ ██████████████░░░░░░░░░░░░ │
  │ A级 35% │ B级 25% │ C级 30% │ D级 10% │
  └────────────────────────────┘

结论：[一句话]
```

### 3. 排名类

#### 条形图（适用场景）
- 商务成本排名
- 商务 GMV 排名
- 产品寄样排名
- 目标完成率排名
- 达人 GMV 贡献排名

**输出格式**：
```
📊 [图表标题]

  张三  ████████████████████ 85%
  李四  ███████████████░░░░░ 72%
  王五  ██████████░░░░░░░░░░ 53%
  赵六  █████░░░░░░░░░░░░░░░ 28%

结论：[一句话]
```

### 4. 漏斗类

#### 漏斗图（适用场景）
- 线索 → 客户 → 商机 → 合同 转化漏斗
- 工单状态漏斗
- 达人开发漏斗
- 客户生命周期升级漏斗

**输出格式**：
```
🔻 [图表标题]

  ┌──────────────────────────────────┐
  │          线索 (150)              │  100%
  └──────────┐          ┌───────────┘
             │ 客户(80) │             53%
             └────┐┌────┘
                  ││商机(35)          23%
                  └┐┌┘
                   ││合同(12)         8%
                   └┘

结论：最大断裂点在 [XX] 到 [XX] 环节，转化率仅 [XX]%
```

### 5. 对比类

#### 表格看板（适用场景）
- 核心指标快照
- 环比/同比对比
- 多维度交叉分析

**输出格式**：
```
📋 [图表标题]

| 指标 | 本周 | 上周 | 环比 | 状态 |
|------|------|------|------|------|
| GMV | 52万 | 48万 | +8.3% | 🟢 |
| 成本 | 3.2万 | 2.8万 | +14.3% | 🟡 |
| ROI | 1:16.2 | 1:17.1 | -5.3% | 🟡 |
| 达人数 | 85 | 82 | +3.7% | 🟢 |

结论：[一句话]
```

### 6. 矩阵类

#### 热力图（适用场景）
- 平台×等级交叉矩阵
- 风险维度交叉
- 商务×指标矩阵

**输出格式**：
```
🔥 [图表标题]

          A级  B级  C级  D级
  抖音    🔴   🟡   🟢   ⚪
  快手    🟡   🟢   🟢   ⚪
  视频号  ⚪   🟡   🔴   ⚪
  拼多多  ⚪   ⚪   🟡   🔴

🔴=高密度  🟡=中密度  🟢=低密度  ⚪=无
结论：[一句话]
```

### 7. 进度类

#### 进度条（适用场景）
- 目标达成率
- 回收进度
- 合同执行进度
- 经营健康度

**输出格式**：
```
📏 [图表标题]

  GMV目标  [████████████░░░░░░░░] 62% (31.2万/50万)  🟡
  达人目标 [██████████████████░░] 89% (80/90)        🟢
  合同数   [██████░░░░░░░░░░░░░░] 33% (10/30)        🔴

⏰ 时间进度：67%（月度第20天/30天）
结论：[一句话]
```

### 8. 四象限类（新增）

#### 散点图/四象限（适用场景）
- 商务投入产出分析
- 达人价值评估
- 资源配置决策

**输出格式**：
```
📍 [图表标题]

         高产出
           │
    ┌──────┼──────┐
    │ 金牛 │ 明星 │
    │ 王五 │ 张三 │
    │ ●    │  ●   │
    ├──────┼──────┤
    │ 观察 │ 问题 │
    │ 陈七 │ 李四 │
    │  ●   │  ●   │
    └──────┼──────┘
         低产出
    低投入 ← → 高投入

  张三  ●(投入3.2万, GMV 25万, ROI 1:7.8) ✓ 明星
  李四  ●(投入2.8万, GMV 8万, ROI 1:2.9)  ⚠️ 问题
  王五  ●(投入0.5万, GMV 12万, ROI 1:24)  ✓ 金牛
  陈七  ●(投入0.3万, GMV 2万, ROI 1:6.7)  → 观察

结论：[一句话]
```

## 角色专属图表清单

### CEO 报告（至少 5 张）
1. 经营健康度仪表盘（多指标进度条）
2. GMV 趋势图（折线 + 目标线）
3. 投入产出对比图（双轴）
4. 风险热力图（矩阵）
5. 团队排名图（条形）
6. 资源配置四象限（散点图）
7. 经营趋势综合图（GMV+达人+成本三线叠加）

### CFO 报告（至少 6 张）
1. 成本趋势图（折线 + 预算线）
2. GMV vs 成本对比图（双轴）
3. 商务投入产出散点图（四象限）
4. 成本用途分布饼图
5. 商务成本 Top10（条形）
6. ROI 变化趋势图（折线）
7. 合同金额周趋势图
8. 产品寄样 Top10（条形）
9. 合同结构分布图（按金额区间）
10. 达人 GMV 贡献 Top10（条形）

### COO 报告（至少 5 张）
1. 工单状态漏斗图
2. 超期趋势图（折线）
3. 商务效率排名（条形）
4. 目标达成进度条
5. 工单紧急分布饼图
6. 回收进度时间线
7. 团队排名变动图
8. 损耗率趋势图
9. 瓶颈环节堆积图

### CMO 报告（至少 6 张）
1. 达人增长趋势图（双线）
2. 达人等级分布环形图
3. 平台分布柱状图
4. 平台×等级交叉热力图
5. 转化漏斗图
6. 账号类型雷达图
7. 销售额层级分布图
8. 增长来源分析图
9. 客户生命周期升级漏斗
10. 达人价值四象限图

## 图表生成注意事项

1. **数据真实**：所有图表数据必须来自 API 返回，不可编造
2. **单位明确**：金额用"万元"（> 10000 时），数量用"个/人/单"
3. **时间标注**：标明数据时间范围（本周 3/25-3/31、本月 3月 等）
4. **ASCII 图表**：在纯文本环境下使用 ASCII 字符绘制可视化图表
5. **Markdown 表格**：结构化数据优先使用 Markdown 表格
6. **颜色指示**：使用 emoji 指示状态（🔴 危险、🟡 注意、🟢 健康、⚪ 无数据）
7. **对比标注**：环比/同比变化用 ↑↓→ 或 +X%/-X% 标注
8. **阈值高亮**：超过预警阈值的数据用 🔴 或 ⚠️ 标注
