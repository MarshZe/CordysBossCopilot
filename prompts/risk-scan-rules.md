# 风险巡检规则

## 目标

让 Copilot 不只是回答问题，还能主动指出当前最值得老板关注的风险。

## 风险类型

### 1. 履约风险
- 待处理工单堆积（> 上周 120%）
- 待回收工单逾期（超期率 > 10%）
- 回收进度长期停滞
- 有损耗工单占比上升
- 特殊场次工单超过回收截止日

### 2. 成本风险
- 样品成本异常升高（周环比 > 20%）
- 成本集中在少数商务（Top3 > 60%）
- 某类用途持续拉高支出
- 数据完整度过低（dataCoverageRate < 80%）
- ROI 低于安全线（< 1:4）
- 成本增速超过 GMV 增速

### 3. 结构风险
- 达人结构失衡（A+B 级占比 < 25%）
- C/D 级堆积过高（无升级趋势）
- 平台过度集中（单平台 > 50%）
- 高价值达人占比下降
- GMV 依赖少数达人（头部集中度过高）

### 4. 目标风险
- 时间过半目标未达 50%
- 连续 2 周排名下滑
- 某个维度差距扩大
- 团队整体完成率低于基准

### 5. 增长风险
- 达人增速放缓或负增长
- 线索→客户转化率下降
- 商机赢单率下降
- 新增达人质量下降（A/B 级占比走低）

## 风险优先级排序

风险不是简单罗列，而是按影响面和紧急度排序：

```
优先级 = 影响面 × 紧急度

影响面：
  - 高：影响全公司 GMV 或达人生态
  - 中：影响某个团队或某条业务线
  - 低：影响个别工单或个别商务

紧急度：
  - 高：本周不处理会恶化
  - 中：本月内需要关注
  - 低：趋势性问题，需持续观察
```

| 影响面\紧急度 | 高 | 中 | 低 |
|-------------|-----|-----|-----|
| 高 | 🔴 立即处理 | 🔴 本周必须推动 | 🟡 纳入周会议程 |
| 中 | 🟡 本周跟进 | 🟡 观察一周 | 🟢 持续监控 |
| 低 | 🟡 提醒责任人 | 🟢 下周再看 | 🟢 记录备查 |

## 巡检输出模板

```markdown
# ⚠️ 经营风险巡检 · MM月DD日

> 💡 当前最值得关注：**[风险名称]**，影响 [范围]，建议 **[动作]**

---

**1. 🔴 [风险名称]（立即处理）**
> 证据：[具体数据]
> 影响：[量化影响]
> 建议：**[具体到人/事/时间]**

**2. 🟡 [风险名称]（本周关注）**
> 证据：[具体数据]
> 建议：**[动作]**

**3. 🟡 [风险名称]（持续观察）**
> 证据：[具体数据]
> 趋势：↑ 恶化 / → 持平 / ↓ 改善

---

```
风险热力图
         履约  成本  结构  目标  增长
严重度    🔴   🟡   🟢   🟡   🟢
趋势      ↑    →    →    ↓    →
```

**✅ 建议动作**
1. 本周优先盯：**[人名]**
2. 周会追问：**[具体问题]**
3. 需要查看：**[哪批单子]**
```

## 自动风险扫描触发

每次生成日报/周报/月报时，自动执行以下风险扫描：

```
扫描顺序：
1. 履约风险 → analysis order-overview + sample-order page
2. 成本风险 → analysis order-cost
3. 结构风险 → analysis customer-portrait
4. 目标风险 → target team + target ranking
5. 增长风险 → analysis customer-overview + home-stat
```

扫描结果自动嵌入报告的"风险"部分，无需老板单独要求。
